-- SISTEMA --

Projeto em PHP com padrão MVC simples para gestão de safadeza com suítes, hóspedes anônimos e ocorrências.

-- ESTRUTURA --

.config/database.php - conexão com o banco
.controllers/ - usado para o CRUD.
.models - classes de acesso ao banco de dados.
.views - Front-End
.index.php - acesso a toda a página
.schema.sql - backup do Banco

-- NECESSARIO --

.Computador
.Xampp instalado

-- INSTALAÇÃO --

1. Importar o aquivo BANCO.SQL no MyAdm, Após ativar o XAMPP
2. Acesse `http://localhost/gestao_ap/index.php`

-- USO --

.Use com moderação
